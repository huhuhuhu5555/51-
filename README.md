## 重点项目：环境监测

### 第一版 —— 温度采集 + 串口上报

- **DS18B20 单总线**：自己实现复位、读写字节、温度解析
- 串口 9600，每秒钟上报一次温度
- 文档：[环境监测项目-实验全过程记录.pdf](51单片机/项目/环境监测/第一版/环境监测项目-实验全过程记录.pdf)

**踩过的三个坑**：

1. 延时函数参数用 `u8` → 循环速度快一倍 → 时序被压缩 → **恒读 15℃**
2. 复位后只等 DQ「变低」就返回 → 应答还没结束就写命令 → 命令丢失
3. 转换没等够 750ms → 读到上电默认值 **85℃**

### 第二版 —— 加上 LCD1602A 显示

- **自己实现 LCD1602A 驱动**（7 个函数，分层设计）
- 并口时序（E 下降沿锁存）、DDRAM 地址、0x80 命令格式、命令/数据双通道
- 屏幕显示温度，串口同步输出
- 文档：[第二版-开发过程与问题整理.pdf](51单片机/项目/环境监测/第二版/第二版-开发过程与问题整理.pdf)

**核心概念**：

- 屏内部有「光标」，写数据落在光标处并自动右移；**程序里没有这个变量**，只能发命令去改
- 第 1 行地址 `0x00~0x0F`、第 2 行 `0x40~0x4F`，写命令时要 `+0x80`
- **屏不会自动换行**，地址只管 +1，换行必须手动设地址
- **RS 引脚决定「命令 vs 数据」**，数值只决定「哪种命令 / 哪个字符」

## 硬件

| 项目 | 型号 / 连接 |
|---|---|
| 开发板 | 普中 A2（STC89C52RC，11.0592MHz） |
| 温度传感器 | DS18B20（单总线，DQ = P3.7） |
| 显示屏 | LCD1602A（并行，RS = P2.6 / RW = P2.5 / E = P2.7 / 数据 = P0） |
| 下载工具 | STC-ISP（USB 转串口） |

## 编译与烧录

1. Keil uVision (C51) 打开对应项目目录下的 `*.uvproj`
2. **Options → Output** 勾选 `Create HEX File`
3. 编译（F7）生成 hex
4. STC-ISP 烧录到 STC89C52（晶振选 **11.0592MHz**）
